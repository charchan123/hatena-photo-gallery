## 採用候補

正式URL、通常記事、RSSをはてなブログに残し、`/` の既存 `#content` の**前**に現在公開済みの `new-top.html` をiframeで追加します。記事一覧、サイドバー、検索、ページャ、はてなヘッダー・フッター・広告は削除も非表示もせず残します。スクリーンリーダーやJavaScript無効時も従来記事へアクセスできます。

起動は「対象ブログorigin」「パス `/`」「page-index」「固有の有効化マーカー」「既存DOM構造」が一致した場合だけ。`?page=...` と `?kinoko-native=1` は従来表示。追跡パラメータや同一originのプレビューqueryは妨げません。`/new-top`、記事、カテゴリには新しいiframeを追加しません。HTML全体の書換え・記事の移動・fetchしたHTMLの挿入・リダイレクトはありません。

通常記事一覧が新トップの下にも残るため、トップ全体は長くなります。これは広告・既存記事・検索導線を安全に残すための選択です。記事を折り畳む／除去するなどの追加デザイン変更は本PRでは行いません。
