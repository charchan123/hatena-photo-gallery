## 公開順序

1. 合格済み子コードをGitHubへ反映しCI確認。データ/画像を直接書き換えない。
2. 公開用子コードを既存Pagesへ配信し本文SHA・匿名表示を確認。日次生成で旧コードへ戻らないソース反映も必要。
3. 親の全画像URL/子URLを公開originへ統一した完全な3欄は非公開成果物で準備。未公開保存と配信先差分確認は管理者の承認範囲で行う。
4. はてな本番公開は結果報告後の別の明示承認を待つ。
