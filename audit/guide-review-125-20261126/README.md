## 元記事の確認方法

対象の関連1件を含む元記事50件の本文を取得し、公開ポータルの画像URLと同一の画像要素かその画像を包むリンクを照合しました。本文ブロック番号は記事本文直下の要素を上から数えた番号です。節見出しは短い同名の独立行または見出し要素として確認し、編集中表記や観察日を括弧で添えた表記は照合時に整形しました。同じ節の名前を確認できた187枚、写真記述に同定留保の候補がある4枚、複合表記2枚、ALTだけが一致していて区別が必要な2枚に分かれました。別の節の名称や、画像から離れた本文の一致だけでは判定していません。元記事の該当位置・留保と、撮影者が名称を確認したこと、写真を種に同定することは別々に扱います。
