# LightGallery PR #142 実機確認ガイド

修正版と修正前を、Windows PCと同じWi-Fiに接続したAndroidのChromeで比較できます。プレビューはPC上で動きます。確認を始めるときだけ起動してください。

## Windowsで起動

1. 配布された `LightGallery_PR142_Real_Device_Preview.zip` を右クリックし、**すべて展開**を選びます。
2. 展開したフォルダーで `START-WINDOWS.cmd` をダブルクリックします。Node.js 18.2以降が必要です。起動できない場合はPowerShellで `node --version` を確認してください。
3. Androidも使う場合は、黒いウィンドウの一覧から、**PCが接続しているWi-Fiアダプター**の番号を入力し、Enterを押します。PCだけなら番号を入力せずEnterを押します。
4. `SHA-256 OK` とURLが表示されたら、黒いウィンドウは開いたままにし、WindowsのChromeで [確認メニュー](http://127.0.0.1:8142/) を開きます。

Windowsのファイアウォールが通信の許可を尋ね、Androidでも試す場合は、ご自宅など信頼できる**プライベートネットワーク**のみに限定してください。PCだけの確認にはLAN接続は不要です。パブリックネットワーク、ルーターのポート開放、ネットワークの認証変更は使いません。

## Androidで開く

1. PCとAndroidを同じWi-Fiに接続します。PC側でWi-Fiアダプターを選んでプレビューを起動します。
2. 起動画面の `Android Chrome:` の行に出た **http:// から末尾の / まで**を、AndroidのChromeのアドレス欄に入力します。途中の英数字は起動ごとに変わります。
3. 確認メニューで「修正後」から検証ケースを選びます。アドレスが開けない場合は、Wi-Fi名・番号・URLの入力を確認します。ゲストWi-Fiなど端末間の通信を遮断するネットワークでは利用できません。職場などで制限されている場合は制限の変更をせず、PC単独で確認するか、許可されている私用Wi-Fiを使ってください。

## 開くページ

Windowsで使うURLです。Androidでは起動画面に出た入口から同じ6つのボタンを選んでください。

同じケースの修正前後を2タブで開き、同じ番号の写真を選ぶと比較しやすくなります。写真を閉じてスクロール復帰を確認してから、別のケースに進んでください。

## Windows Chromeのチェックリスト

- [ ] 写真08以降までスクロールし、見えている写真番号を覚えてから1枚開く。
- [ ] 右上の×の右に余白があり、虫眼鏡と×が修正前より少し近い。幅769px以上では、×の右余白18px、虫眼鏡との中心間隔46pxが目安。
- [ ] 開いている間だけ右端の縦スクロールバーが消える。×で閉じるとバーが戻り、同じ番号の写真が同じあたりに表示される。
- [ ] Chromeのウィンドウを狭めても写真や操作ボタンがはみ出さない。
- [ ] 再度開いてEscで閉じ、同じ位置に戻る。
- [ ] 写真を閉じた状態で「確認用一覧へ戻る」を押し、Chromeの戻る／進むで写真一覧との間を移動できる。

Windowsでバーを常に表示しない設定の場合は、修正前でもバーが見えないことがあります。そのときは、開いた写真の外側が勝手にスクロールしないかと、閉じたときの位置を確認してください。

## Android Chromeのチェックリスト

- [ ] 写真08以降を開き、右上の×が表示されていてタップしやすい。
- [ ] 虫眼鏡で拡大・縮小できる。拡大を解除し、写真を左右にスワイプすると別の写真に変わる。
- [ ] 下のサムネイルをタップすると、その写真に切り替わる。
- [ ] 共有ボタンで共有メニューが開く。共有先をタップすると検証用の案内が表示される。
- [ ] ☆をタップしてお気に入りの追加・解除ができる。
- [ ] 写真の下に撮影情報が表示される。例は「Macro 60mm」「F5.6」「ISO400」。
- [ ] 写真を開いたまま縦向き／横向きに回転できる。写真や×が切れず、意図しない横スクロールがない。
- [ ] ×で閉じると、開く前にいた写真番号付近に戻る。

Androidは縦バーをスクロール中にだけ一時表示する場合があります。見え方に差がないときは、位置復帰を中心に確認してください。気になる動作があれば、端末、修正前／修正後、ケース名、写真番号、操作を控えてください。

## 検証対象と安全性

- 修正後の `gallery.css` と `gallery.js`、LightGallery関連資産はPR #142の検証済みコミット `02135b9adb5aaac03ee9006b55f724fa86356d17` から取得しています。修正前はCIで比較した公開スナップショット `ae08f456729e7d89619af9569b7daecdd85080cd` です。
- 親ページとギャラリーは別ポートで配信します。固定フッターの親ハンドラーを使い、子の信頼する親オリジンだけを試験用URLに置き換えます。親のスクロールバー用CSSは修正後の2つの埋め込みページだけに適用します。直アクセスでは子のCSSを単独で確認できます。
- 写真カードは既存レンダラーを使い、画像・EXIFは検証用のサンプルです。共有先は確認用表示に置き換えています。☆はプレビュー用オリジンのブラウザ内に保存されます。通信はローカルの2ポート内で完結し、外部APIを呼びません。
- 外部ホスティングや追加料金はありません。Android向けのHTTP接続は、選んだプライベートIPv4の同じサブネットと起動時のランダムURLに限定します。通信自体は暗号化されないため、信頼できるWi-Fiで使い、Android用URLは共有しないでください。
- この再生は本番のはてなテーマ全体を読み込むものではありません。本番テーマとの組み合わせとWindows／Androidの実機結果は、確認後に別途判断します。

## 終了と削除

黒いウィンドウで **Ctrl+C** を押すか、ウィンドウを閉じます。起動から120分でも自動停止します。再起動するとAndroid用URLは新しくなります。不要になったら展開フォルダーとZIPを削除してください。お気に入りも消したい場合はChromeでプレビュー用アドレスのサイトデータを削除できます。
