# 個別審査への引き継ぎ

1. P0の [18種の記録](p0-review.md) を確認する。特にナラタケの相談と中毒例、キララタケの県資料間の違い、カキシメジ・クサウラベニタケの種の範囲を先に読む。
2. [文章比較](wording-changes.csv) で、今回新たに表示する箇所を審査する。クロカワは分類体系、チャアミガサタケは変種への適用、キイロスッポンタケとミヤマタマゴタケは通常の発生期間が次の確認点。
3. [審査一覧](review-queue.csv) のBは主表示・食毒区分・分類の個別候補。カラカサタケは食用記載を先に見せる現行の見出しを「資料に食用記載と注意情報があります」にする候補を、既存承認済み文言の個別審査に回す。島根県の注意の理由は引き続き未確認。
4. 生態の未確認58種は、まず掲載写真数の多いアカヤマドリ（旧 *Leccinum* と新しい属）、オオワライタケ（旧 *Gymnopilus spectabilis* と *G. junonius*）、アミガサタケ類（種範囲と生活様式）を、同定された国内標本と種別研究から調べる。キクバナイグチは旧広義名の生活様式を分割後の種に移さない。
5. 旧方式の写真80枚については [既存一覧](../guide-85-20261123/photo-review-80.csv) の記録、原記事、必要な部位が写る写真、採集記録・標本番号を人間の同定審査で照合する。学名変更と食毒変更は個別に扱う。
