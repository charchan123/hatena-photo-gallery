## レビュー時に確認する点

- ナラタケは平成15年度の「35件」を相談数として補足した。食用の相談上位一覧から外したという茨城県の判断を、症例の件数や種の毒性判定とは区別した。
- クロカワは京都府・静岡県の `Boletopsis leucomelaena` の記載を併記し、特徴・生育環境・発生時期と外生菌根を表示する。主表示の学名、既存の科、採集写真への適用は独立審査。
- キイロスッポンタケは1996年の新名発表と京都の再確認記録を結び付けた。発生月は一地域の記録。
- 生態は種別資料で生活様式を確認した。山田明義（2002）の生態根拠は表2。属の日本語名は同論文のp.2の属名一覧などから照合した。撥音・訳語を推測で補わず、表示中の学名に対応する科・属の日本語を選んだ。
