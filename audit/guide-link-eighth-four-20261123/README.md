## 既存の食毒原メモと読者向け表示文

### アンズタケ

- 原メモ：食用可否の自己判断には使用しない。毒性の記録がないことは安全を意味しない。 石川県の食毒欄は「食」。公的資料に食用記述があるという記録であり安全保証ではない。 島根県の公的一覧には「アンズタケ（注意）」と掲載される。注意理由は当該一覧だけでは未確認であり、毒性・毒成分・発症条件を推測しない。資料上の食用記録は安全保証ではない。
- 表示文：石川県の資料では、食毒欄に「食」と記載されています。一方、島根県の資料では「アンズタケ（注意）」として掲載されています。この一覧だけでは注意が必要な理由までは確認できないため、毒性や発症条件を決めつけることはできません。資料の食用記載は、採取したキノコの安全性を保証するものではありません。
- 留保：石川県の「食」と島根県の「注意」の両方を出す。注意の根拠を推定せず、掲載学名と科の保留も維持する

### カキシメジ

- 原メモ：食用可否の自己判断には使用しない。毒性の記録がないことは安全を意味しない。 石川県の食毒欄は「毒」。 厚生労働省は中毒症状または事例を記載。
- 表示文：石川県の資料では、食毒欄に「毒」と記載されています。厚生労働省の資料には、嘔吐や下痢などの中毒症状・事例が記載されています。ただし、これらの資料だけで写真に写る個体の種を特定できるわけではありません。
- 留保：2021年研究による旧カキシメジ概念の再検討を踏まえ、写真の再同定や毒成分の種別帰属は行わない

### カバイロツルタケ

- 原メモ：食用可否の自己判断には使用しない。毒性の記録がないことは安全を意味しない。 石川県の食毒欄は「食」。条件付き毒性記述／注意記述があるため食用判定へ変換せずunknownとした。
- 表示文：石川県の資料では、食毒欄に「食」と記載されています。一方、森林総合研究所の資料には「生食すると毒だといわれる」と記載されています。食用という記載だけで安全とは判断できず、加熱すれば安全という意味でもありません。
- 留保：`unknown` を維持。資料の伝聞を確定毒性に変換せず、調理により安全との推測もしない。掲載学名と `Amanita fulva` の対応保留を維持する

### クサウラベニタケ

- 原メモ：食用可否の自己判断には使用しない。毒性の記録がないことは安全を意味しない。 石川県の食毒欄は「毒」。 厚生労働省は中毒症状または事例を記載。
- 表示文：石川県の資料では、食毒欄に「毒」と記載されています。厚生労働省の資料には、嘔吐や下痢などの中毒症状・事例が記載されています。ただし、これらの資料だけで写真に写る個体の種を特定できるわけではありません。
- 留保：2017年研究の日本産旧 `E. rhodopolium` 種群の再検討を踏まえ、旧名から新しい各種への毒性一律適用や写真の再同定は行わない
