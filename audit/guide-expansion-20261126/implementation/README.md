### 既存の承認と切り離した追加方法

特徴検索側には承認済みのマスター・出典ファイルと、取り込み台帳をバイト単位で照合する仕組みがある。そのため新規20種は同じマスター・出典スキーマの [追加データ](../../../data/guide-expansion.json) として保持し、同期の照合が済んだポータルの専用フィールドに格納し、図鑑の詳細表示で読み合わせる。既存ポータルのマスター・出典フィールドは旧版と完全一致し、他機能は従来のフィールドを使用する。既存のマスターファイル141種、出典419件、既存リンク34件、分類台帳、特徴検索の承認データはそのまま読む。

接続はこの20種の和名、既存分類台帳の正規名、各公開写真の既存分類結果が完全一致する場合に限る。以前の分類方式、疑問符・別名・部分一致、分類未検出が混在する場合は接続しない。将来、同名の写真を含む公開グループの分類状態が要確認に変わった場合、追加解説への接続を保留したまま生成を続ける。写真・記事の属性と分類台帳を書き換えない。
