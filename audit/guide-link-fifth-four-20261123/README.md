## 食毒に関する重要事項

- テングタケは石川県と厚生労働省の資料の毒性評価・中毒症状に基づき、`poisonous_confirmed` を保ちます。
- ニガクリタケは死亡例を含む中毒事例を記載します。ファシキュロール類等の報告成分を、致死的な中毒の確定原因と取り違えないようにします。
- ツルタケとヌメリイグチの「食」は出典の区分であり、写真に写る個体や野生個体の安全性の保証ではありません。
- 全種類で摂食判断への使用を禁じる共通注意書きを残します。新しい文章はID・和名・元メモ全文の一致時のみ適用します。
