## 検証と再開

`python audit/guide-105-enrichment-20261128/verify.py`。公開ポータルを入力に全105種の表示を比較し、追加欄の出典、既存の警告と出典の保持、対象外のハッシュを照合します。コメント回帰試験の既存保護を維持し、この基準mainの表示専用JSONに限って正確なGit blobを追加しました。既存ワークフローのブラウザ比較は読み取り専用です。

再開時は最新mainとgh-pagesを再取得し、同期差分と公開件数を確認します。出典と学名の適用範囲、旧分類ラベルの注記、変更対象の一覧を個別審査します。原稿準備の別Draftや管理室の承認履歴と、この表示専用データの審査を独立して扱います。
