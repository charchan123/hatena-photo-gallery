## 表示データと審査

[日本語表示データ](../../data/taxonomy-display-ja.json)には元レコードのID、和名、学名、科・属の元値、表示名、分類学名、表示専用の出典を保存する。種名・分類が変わった場合は登録済み表示を適用せず再審査に回す。学名の原文は維持する。ラテン語の既存科・属を日本語で裏付けられない場合は「確認中」とし、出典の表記は補足に表示する。既存の日本語表記をそのまま使う場合は出典資料の表記として表示する。

生態は生育環境から独立させた。資料に明示された腐生菌・菌根菌を候補にし、倒木や林床での発生場所だけから推定しない。寄生と腐生の両方が記載される場合は、単一ラベルを適用する前に、生活様式と出典の範囲を並べて審査する。現段階の実装は裏付けがある11件の表示に限定。

## PC・スマホ検証

`browser_fixture.py` は公開済み85ページを固定し、図鑑情報パネルだけをDraftのレンダラー出力に置換する。パネル外のバイト一致を検査し、写真・本文・既存のUIを保護する。CIでChromiumの1440pxと390px、元版とDraftの合計340ケースを比較し、はみ出し、文字の重なり、警告、出典リンク、LightGallery開閉とスクロール位置を確認する。外部の写真は同サイズ比のテスト画像を使い、配信操作を伴わずに検証。結果と代表ページの画像はGitHub Actionsのアーティファクトで閲覧可能。

変更範囲は表示レンダラー、日本語表示専用データ、読み取り専用の検証と本資料。記事・写真・分類台帳・マスター・既存出典・食毒区分・承認履歴は保護した。審査時はまず、エノキタケ・シイタケの新旧表記の見せ方、11種の生態表示、確認中の文言を確認する。その後、P0の食毒・分類資料と80枚の写真照合を個別に進める。
