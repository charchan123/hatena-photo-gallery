# スマホのスター間隔とPC・スマホ共通LightGallery

基準main: `8007a72708aff2dfa14e2e9638f44720bb449b76`（PR #138マージ済み）。
Draft PR: https://github.com/charchan123/hatena-photo-gallery/pull/139

## 原因と最小修正

- スター: `.record-stars-native` が横幅の余剰を引き受けるため、スターと省略表示・件数の間が広がっていた。680px以下の新トップのみ外枠を内容幅にし、公式追加コントロールの予約幅を36→32pxへ変更。既存プロフィール合成画像の縮小率を0.9→1にして内部余白を詰める。タップ対象28px以上、公式DOM・追加処理・件数・「…」を維持。PCは既定値を保持。
- Best Shot: iframe表示では独自のHTML `dialog` に原寸画像を入れており、図鑑のLightGalleryの寸法・ツールバーCSSを通らなかった。Best Shotを図鑑と同じLightGallery初期化、2.8.3依存、プラグイン、スタイルへ接続。独自dialogは研究室の既存動作専用として保持。
- 親iframeの開く前の認証付きACKを共用し、閉じる通知はアニメーション完了後に送る。親が捕捉した位置への復帰と、`preventScroll`によるフォーカス復帰を維持。親側CSS・Header・Footerの変更は不要。
- キャプションは同じカードの名前・撮影日・場所・コメント・年間ベストを安全にエスケープして生成。撮影日の手動登録・選択・並び・年間Best・保存形式を変更しない。元のBest ShotカードにカメラEXIF表示はなく、追加推測しない。
- 外部依存が遮断された場合は共通ギャラリーの起動を見送り、元の写真リンクとページ初期化を保持する。

## 製品ファイル

| ファイル | 変更 |
| --- | --- |
| assets/record-stars.css | 新トップのスマホ幅だけの間隔調整 |
| assets/record-stars.js | 公式コントロール幅をCSS変数で指定可能にする |
| assets/gallery.js | 共通初期化・既存ACK・閉じた後の復帰へBest Shotを接続 |
| gallery_dependencies.py | 既存LightGalleryタグ定数を一箇所へ抽出 |
| main.py | 同じ定数をimport（タグ内容は不変） |
| best_shot_ui.py | 同じ依存を一度だけ読み込み、対応するキャプションを追加 |

テストには、過去の凍結済みgallery.jsをそのまま保存したfixtureを追加。過去候補のハッシュ条件は変更せず、現在の動作試験は修正後コードを使用する。旧HTML比較は追加依存とキャプションを独立検証したうえで全カード構造を比較する。公開済みスナップショットのマーカーは、起動有無を選ぶ試験内だけで取り除いてから再注入する。
