## 元の食毒メモと表示文

### ナラタケ

原メモ：
食用可否の自己判断には使用しない。毒性の記録がないことは安全を意味しない。 石川県の食毒欄は「食」。公的資料に食用記述があるという記録であり安全保証ではない。 茨城県はナラタケ類の摂食後事例と、ナラタケ・ナラタケモドキの多量摂取による消化不良への注意を記載する。原因種が確定した毒性試験と同一視せず、食用記録に注意を併記する。

表示文：
石川県の資料では、食毒欄に「食」と記載されています。一方、茨城県の資料では、ナラタケやナラタケモドキについて、食べ過ぎると消化不良を起こしやすいと注意しています。食用との記載があっても、採取したキノコの種類や安全性を判断することはできません。

採用根拠（収録済み）：
- `research-ishikawa-naratake` 石川県「ナラタケ」https://www.pref.ishikawa.lg.jp/ringyo/kinoko/data/naratake.html （「食」）
- `audit-naratake-ibaraki` 茨城県「野生きのこ相談室（平成12年度）」 https://www.pref.ibaraki.jp/nourinsuisan/ringyose/seikkinoko/sodan12.html （ナラタケ・ナラタケモドキの多量摂取について消化不良の注意）

**追加確認した公的資料：** 茨城県「野生きのこ相談室（平成15年度）」 https://www.pref.ibaraki.jp/nourinsuisan/ringyose/seikkinoko/sodan15.html には、同県の相談状況に基づき、ナラタケについて中毒例があるとして食用の一覧から外した旨も記載されている。今回の変更ではこの追加資料をマスター出典には未収録のため、その内容をマスター事実として確定・再分類しない。**食用評価を統一できていないため、今後の出典追加・再審査の課題として残す。** 読者向け画面でも食用表示だけを強調せず、具体的な注意を併記する。「調理すれば安全」「食べ過ぎなければ安全」とは説明しない。

### マンネンタケ

原メモ：
食用可否の自己判断には使用しない。毒性の記録がないことは安全を意味しない。 石川県の食毒欄は「薬用、鑑賞」。

表示文：
石川県の資料では、食毒欄に「薬用、鑑賞」と記載されています。これは資料に記された利用区分であり、薬としての効果や、採取したキノコの安全性を示すものではありません。

採用根拠（収録済み）：
- `research-ishikawa-mannentake` 石川県「マンネンタケ」https://www.pref.ishikawa.lg.jp/ringyo/kinoko/data/mannentake.html （「薬用、鑑賞」）

マンネンタケは、資料の用途記録から薬効・臨床的効果・食毒区分を判断しない。`unknown`を維持する。資料での目・科の分類不一致など保留事項もそのまま保持する。
