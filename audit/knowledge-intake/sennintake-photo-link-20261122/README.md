## 原典の照合

1. 静岡県『静岡県レッドデータブック（2020）』p.453。掲載学名は *Albatrellus pes-caprae*、科はニンギョウタケモドキ科。傘の形・表面、管孔、柄への垂生、色、季節、県内の生育環境を確認した。
2. J.A. Stalpers (1992), “Albatrellus and the Hericiaceae”, *Persoonia* 14(4): 537–541, p.539。*A. pes-caprae* では不規則で浅い管孔の間に針状突起が混在することが記載される。
3. 2024-10-27の観察記事は、師匠からセンニンタケと教わった記録と、裏面の針状突起の観察を記載する。Stalpers (1992) の記載により、これを静岡県資料の管孔記載と直ちに矛盾するものとは扱わない。
4. 2025-11-01の記事は前年と同じ場所で見られたと記載する。これは観察履歴の補助情報であり、独立した分類学的証拠とは扱わない。
