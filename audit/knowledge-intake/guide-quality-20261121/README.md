## 15種の食毒情報

既存候補すべての食毒欄は現行の `unknown` のまま。この作業で管理室の判断、採用バッチ、公開の分類データは作成していない。旧資料が示す毒性記載と、現在の分類範囲にその記述を適用できるかを項目ごとに分けて照合した。

- **修正文の審査候補2種**。クロタマゴテングタケは *Amanita fuliginea* で公的資料と査読論文が対応する。フジウスタケは旧学名と現行の属名の対応を分類論文で確認し、JATAFFの当該種向け資料に中毒リスクの記載がある。食毒文に使う候補は「対象種について毒性または中毒リスクが報告されている」まで。採用時は根拠を添えて人が確認する。
- **国内事例を確認し、個別同定は保留2種**。オオキヌハダトマヤタケとカオリツムタケは食品衛生学雑誌の原因種欄に和名で載る。集計は推定事例も含むため、事例と現行学名の適用範囲を確認する。
- **毒性欄を未確認とする11種**。旧学名の適用範囲、同名・近縁との混同、対象種独自の資料の有無を記録した。ウスキテングタケは国内の新しい資料で *Amanita orientigemmata* と扱われる。旧 *A. gemmata* の候補欄へは転記せず、学名の照合後に再審査する。
